Kashi Ghar store, now with a NestJS backend

The Lab 3 e-commerce store was copied, and every piece of its data (products, accounts, carts, coupons, orders and reviews) now comes from a NestJS backend written in TypeScript. The backend has controllers, services, DTOs with class-validator, a login guard, and saves everything to a JSON file.

Open the store demo API documentation (Swagger) Source code

GitHub Pages can only serve files, not run NestJS. On this site the store demo uses a stand-in API that runs in your browser with the same endpoints. Run the backend on your computer (below) to use the real NestJS server.

How it fits together

Store pages (frontend/) fetch() + Authorization: Bearer Controllers + ValidationPipe (DTOs) + AuthGuard Services (business rules) DatabaseService → data/db.json

CatalogModule

Products with filters, search and sorting, categories and delivery options. The admin can create, replace, update and delete products.

AuthModule

Signup and login with PBKDF2-hashed passwords and login tokens. A global AuthGuard checks the @Auth('user' | 'admin') each route needs.

CartsModule

Carts kept on the server, quantities capped at the stock, and the MULTAN10 / KASHI500 coupons. Totals are worked out for standard and express delivery.

OrdersModule

Checkout with nested DTOs for contact, shipping and payment (full card numbers are refused). Ordering takes items out of stock, and cancelling puts them back.

ReviewsModule

Reviews, marked "verified buyer" when the writer is logged in. Each product's rating and the shop-wide star summary update straight away.

DatabaseModule

A global DatabaseService that loads data/db.json, creates it from the Lab 3 catalogue on the first start, and saves with an atomic write.

Run the real backend

cd "Lab 8/backend"
npm install
npm start          # http://localhost:3000/store/  (store)
                   # http://localhost:3000/docs    (Swagger)
npm test           # 9 tests, including a restart

You need Node.js 20 or newer. The demo accounts are demo@kashighar.pk / demo1234 (customer) and admin@kashighar.pk / admin1234 (admin).

Main endpoints

GET/api/productsfilter, search, sort
POST/api/auth/loginreturns a token
POST/api/carts/:id/itemsadd (stock-capped)
PUT/api/carts/:id/couponapply coupon
POST/api/orderscheckout (login)
PATCH/api/orders/:idcancel / ship
DELETE/api/products/:idadmin only
