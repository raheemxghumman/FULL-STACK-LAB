roundMe()

A rounding function that accepts any number of arguments: none returns 0, one returns a number, and several return an array. The rounding is written by hand instead of calling Math.round.

  • rest parameters ...args
  • arguments length
  • arrays
  • modulo %

Task statement

Create a roundMe() method. roundMe function can work on 0 - N arguments, for multiple arguments, it returns an array of rounded values.

roundMe() // returns 0 roundMe(4.7) // returns 5 roundMe(4.7, 4.4) // returns [5, 4]
