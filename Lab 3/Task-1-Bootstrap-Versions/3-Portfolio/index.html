It grew out of the exam-guide sites I made for my own class (CN, COAL, SE and Civics mids) when classmates kept asking for the same notes.

Real-time Chat App

Sign up, log in, see who's online and chat live over Socket.IO. Profile updates, image uploads through Cloudinary, theme switching with DaisyUI, and an in-memory MongoDB fallback that keeps local testing painless.

State lives in Zustand on the client; the Express API handles auth and messages.

React · Vite · Express · MongoDB · Socket.IO · Zustand · Tailwind View on GitHub

CIRO — Crisis Intelligence & Response Orchestrator

A hackathon build: real-time, AI-powered crisis detection, reasoning and response planning. Agents are built on Google's Agent Development Kit.

The front-end is hosted on Firebase and the backend API runs on Google Cloud Run.

AI agents · Google ADK · Firebase · Cloud Run View on GitHub

Insta Downloader

Paste a public Instagram reel, post or video link, preview it in the player and download it as an MP4.

The Express backend resolves the media server-side and proxies the stream, so the third-party source endpoint is never exposed in the front-end code.

React · Vite · Node.js · Express View on GitHub

NexaLAN

A LAN-first communication and collaboration platform for software houses: direct messaging, project workspaces, company announcements, file sharing, a GitHub-style repository simulation and an activity audit trail.

Styled after WhatsApp Desktop and built to run entirely on a local network with no internet dependency.

.NET 10 · Blazor Server · C# · SignalR Private repository
